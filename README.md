# 내 자산 관리 (Trade)

개인용 **주식 포트폴리오 관리 + 암호화폐 자동매매** 웹앱입니다.
웹/모바일 브라우저에서 바로 열어 사용합니다.

## 주요 기능

### 주식 포트폴리오
- 한국(KRX/코스피·코스닥) + 미국(NYSE/NASDAQ) 종목 지원
- 한글·영어·티커로 종목 검색 후 보유 종목 등록 (수량·평균 매입가)
- 실시간 시세, 평가손익·수익률 자동 계산
- 자산 배분 파이차트 + 종목별 가격 차트
- 미국 주식은 원화로 환산해 총 평가금액 표시 (환율 자동 갱신)

### 암호화폐 자동매매
- 바이낸스 / 업비트 연동 (ccxt)
- RSI, 이동평균 교차(골든/데드크로스) 전략
- 과거 데이터로 백테스트 (수익률·승률·매매횟수)
- 봇 생성 후 자동 매매 (node-cron)

## 안전장치
- 기본 **페이퍼(모의) 모드** — 실제 주문 없이 동작
- 바이낸스 **테스트넷** 기본 사용
- 1회 주문 한도 / 일일 매매 횟수 제한
- API 키는 `server/.env` 에만 저장하며 **절대 커밋되지 않음** (`.gitignore` 처리)

## 기술 스택
- 프론트엔드: React 18 + Vite + Tailwind CSS + Recharts
- 백엔드: Node.js + Express
- 데이터: Yahoo Finance(주식 시세·검색), ccxt(거래소)

## 실행 방법
```bash
npm run install:all   # 루트 + server + client 의존성 설치
npm run dev           # 프론트(5173) + 백엔드(4000) 동시 실행
```
- 프론트엔드: http://localhost:5173
- 백엔드 API: http://localhost:4000

## 자동매매 키 설정 (선택)
시세 조회·백테스트·페이퍼 트레이딩은 키 없이도 됩니다.
실거래 연동이 필요할 때만:
```bash
cp server/.env.example server/.env   # 복사 후 키 입력
```
`server/.env` 는 절대 공개 저장소에 올리지 마세요.
